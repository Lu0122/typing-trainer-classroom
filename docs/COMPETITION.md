# 比赛模式说明

面向校内打字比赛的多人赛制。入口 `/#competition`，大屏 `/board`，成绩导出 CSV。

## 一、赛程时间轴

### 个人赛（晋级赛）

| 阶段 | 时长 | 发生什么 |
| --- | --- | --- |
| `waiting` 检录 | 240 秒 | 学生陆续登录并加入。第一个加入的人是房主，可点「立即开始初赛」提前开赛 |
| `qualifier` 初赛 | 90 秒 | 全员同题作答，按正确字数排名，取前 16 名晋级 |
| `break` 公布晋级 | 20 秒 | 显示晋级名单，未晋级者转为观战 |
| `final` 决赛 | 60 秒 | 只有 16 名晋级选手计分，题目换成更难的挑战档 |
| `finished` 结算 | 30 秒 | 显示冠军与前三，展示结束后房间自动重置，可开始下一场 |

### 团队赛

`waiting` → `qualifier` 90 秒 → `finished`。只打一轮，加入时自动按人数均衡分到红队 / 蓝队，比两队总正确字数。

**赛程是自动推进的**：到点由服务端切换阶段，不需要老师点按钮。因为本模式没有独立主持台，靠人工推进会出现「初赛结束没人开决赛」的卡死。老师只需要保证网络和投影。

## 二、晋级规则

- 初赛按 `正确字数 → 准确率 → 速度` 排序，前 16 名晋级（`config.finalists`）。
- 参赛人数不足 16 人时，全部晋级。
- 被判定「成绩作废」的选手不占晋级名额，也不参与排名。
- 未晋级者不会离开房间，可以在决赛期间观战，学生端会显示「你未晋级决赛，正在观战」。

## 三、题目

题库在 `backend/competition-texts.js`，按难度分三档，每档 8 篇：

| 档位 | 篇幅 | 特点 | 用在哪 |
| --- | --- | --- | --- |
| `basic` 入门 | 74–88 字 | 常用字、简单标点 | 备用 / 低年级 |
| `standard` 标准 | 76–89 字 | 书面语、成语、长句 | **初赛** |
| `challenge` 挑战 | 71–113 字 | 混入数字、英文、符号 | **决赛** |

约定：
- **同一轮所有人同一篇**，按序号取题，打满一段按回车换下一篇。
- **题面里不允许出现空格**。判定是逐字比对原始字符串，题面有空格就必须真敲空格；而中文输入法用空格上屏，极易多打一个空格被判错。需要留白用中文标点断开。

## 四、计分与排名

- 只统计本轮（初赛 / 决赛分开记），换段不清零。
- `正确字数` = 逐字比对命中的字数；`准确率` = 正确 / 尝试。
- `速度` = 正确字数 ÷ 本轮已用时间 × 60000（字/分），服务端统一计时，客户端只显示。
- 排名依次比较：正确字数 → 准确率 → 速度。
- 结算写入 `training_sessions`（成长记录，按轮次分键）与 `competition_results`（整场结果 JSON）。

## 五、防刷分

前端 `@paste.prevent` 挡粘贴，但真正兜底在服务端：

| 校验 | 规则 |
| --- | --- |
| 前缀一致 | 提交内容必须是已结算部分的**前缀扩展**，不能改已结算的字 |
| 单批上限 | 单次最多 16 字 |
| 幂等 | 重复提交同一内容不加分 |
| 速率窗口 | 3 秒滑动窗口内累计新增 > 45 字（15 字/秒）记一次异常 |
| 作废 | 异常累计 3 次 → 本轮成绩作废（仍可留房观战，不会被踢出） |

阈值为什么是 15 字/秒：人类极限约 10 字/秒，正常选手 2–4 字/秒，不会误伤；而绕过前端直接打接口刷分必然超过。异常只在成绩单里标「速率异常 / 成绩作废」，不做硬拒绝，避免网络抖动把选手误判出局。

## 六、大屏投影

地址：`/board?mode=personal` 或 `/board?mode=team`。

- **免登录**，投影机随便开一台即可，接口 `GET /api/competition/:mode/board` 只返回公开字段，**不含 seat 令牌**（避免把身份令牌投到墙上）。
- 内容：大号倒计时、实时前 12 名（进度条 + 正确字数 + 准确率 + 速度）、晋级名额 / 已晋级人数、赛场动态。
- 整页一屏，不出现滚动条（1920×1080 / 1366×768 均已验证）。
- 学生端右上角有「大屏模式 ↗」，点击新开标签页。

## 七、成绩导出

比赛页结算后点「导出成绩单（CSV）」，或直接访问：

```
GET /api/competition/personal/export.csv
GET /api/competition/team/export.csv
```

- 数据取自 `competition_results` 表里**最近一场已结算**的比赛，服务重启也不会丢。
- 带 UTF-8 BOM，Excel 双击打开中文不乱码。
- 列：`排名 / 姓名 / 账号 / 初赛正确字数 / 初赛排名 / 决赛正确字数 / 决赛排名 / 准确率(%) / 速度(字/分) / 是否晋级 / 状态`
- 包含**所有参赛者**，不只是晋级的 16 人；未晋级者决赛列留空。

## 八、现场组织流程

1. 提前在管理后台确认学生账号可用，机房机器能访问服务地址。
2. 投影机打开 `/board?mode=personal`，先确认页面能连上（显示「检录中」）。
3. 学生登录 → 进大厅 → 点「比赛模式」→ 点「加入比赛」。
4. 人齐后老师用自己那台点「立即开始初赛」，或等 4 分钟自动开始。
5. 初赛 90 秒 → 自动公布晋级 → 自动开始决赛，全程不用操作。
6. 结算后点「导出成绩单」，得到 CSV。

**注意**：比赛房间存在服务端内存，**重启服务会丢掉进行中的对局**。比赛期间不要重启。

## 九、接口一览

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/competition/:mode` | 学生 | 我的视角完整状态（含题目与 seat） |
| POST | `/api/competition/:mode/join` | 学生 | 加入（仅检录期） |
| POST | `/api/competition/:mode/start` | 房主 | 提前开赛 |
| POST | `/api/competition/:mode/type` | 学生 | 提交输入（≤16 字，前缀扩展） |
| POST | `/api/competition/:mode/next` | 学生 | 换下一段（需打满当前段） |
| POST | `/api/competition/:mode/leave` | 学生 | 退出 |
| GET | `/api/competition/:mode/board` | **免登录** | 大屏数据（不含 seat） |
| GET | `/api/competition/:mode/export.csv` | 学生 | 最近一场成绩单 |

`:mode` 取 `personal` 或 `team`。

## 十一、已知边界

- 比赛房间是**单一公共房间**：全校共用一场，不能同时开多个赛场。要分批比赛需等上一场结算并重置（约 30 秒）。
- 没有老师主持台（建赛 / 暂停 / 加时 / 踢人），赛程按固定时长自动跑。
- 成绩单没有「班级」列：`users` 表目前没有班级字段，需要按班统计得先给用户体系加字段。
- 检录期结束就不能再加入，迟到的学生只能等下一场。
