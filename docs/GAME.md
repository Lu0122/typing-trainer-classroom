# 红蓝打字占领战

首页点击「游戏模式」进入大厅，再选择「红蓝占领战」，也可直接访问 `/#battle`。所有人连接同一台电脑的 Node 服务，使用各自的已启用学生账号。大厅同时提供竞技玩法「极速淘汰赛」，规则见 README 的“联机游戏选择”。

- 单一公共房间 1024，每局最多 60 名参赛者。
- 第二位玩家加入自动开局；若都选同一方，自动分到红蓝两边。
- 连续输入正确字符会自动发动轻量攻击并逐步占领领地；完整输入后可按回车进入下一段。
- **连击威力放大**：每个字符的占领效率由当前连击决定，连击 5/15/30 分别提升到 1.5/2.5/4 倍，连击越高推进越快；打错会立刻清空连击并回落到基础威力。界面会显示当前档位和升级进度。
- 每局使用统一的有序题库：所有玩家从第 1 段开始，完成后按自己的速度进入下一段；未完成的玩家保留当前题目和进度，不会随机换到另一篇难度不同的文字。输入区会显示当前段序号。
- 输入完整一段后按回车只会进入下一段，不会额外产生攻击；攻击和占领只由服务端确认的正确字符触发。输入有错误时也可以在完整输入后回车跳到下一段，但错误部分只计入尝试，不计入攻击。
- 两队在线人数差超过 2 人时，每 30 秒自动调平；被调队者领取新题。
- 15 秒无心跳视为离线；刷新后可恢复身份，未提交的本地输入会清空。
- 一方占领 100% 后结束，弹窗左右显示双方前五名，按正确字数、准确率排序，各队第一名为 MVP。
- 结算保存至 SQLite 的 `battle_results` 表；20 秒后在线玩家自动进入下一局。
- 当前对局存在服务端内存中，重启服务会重置当前对局，已保存结算保留。

## 局域网

运行 `npm start`，学生通过 `http://服务器局域网IP:3000/#battle` 访问。所有设备需网络互通，服务器需允许入站 TCP 3000。

每客户端每秒同步一次状态。`test/battle-api.test.js` 使用隔离内存数据库模拟 60 个身份并发加入、同步状态、攻击与结算；这不等于已在 60 台真实电脑上完成网络压测。
