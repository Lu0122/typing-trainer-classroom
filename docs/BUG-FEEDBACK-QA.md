# 学生端「问题反馈」改版

## 改版原因

原页面是**测试工程师的缺陷单**：9 个字段、4 个必填，标签是「前置条件 / 测试数据 / 预期结果 / 复现频率 / 优先级 P0-P3」。
大一学生在机房遇到问题时只会说「音游里音符掉太快」，填不动这些字段就只能乱填，或者干脆不反馈。

现在改成**只问 3 件事**：一句话说清 → 点几个标签 → 可选截图。专业字段收进折叠区。

## 现在的填写流程

| 区块 | 必填 | 说明 |
|---|---|---|
| 说清发生了什么 | ✅ | 唯一必填项，120 字。占位符给出「在哪 + 看到什么」的范例 |
| 是哪个功能？ | | 12 个标签，点一下选中；从游戏页点「反馈」进来会自动选好 |
| 具体是什么情况？ | | 7 个标签，可多选（卡住不动 / 画面错乱 / 分数不对 / 打不了字 / 进不去 / 声音异常 / 其他） |
| 还能继续玩吗？ | | 三档人话：还能玩（P3）/ 玩不下去（P1）/ 完全进不去（P0） |
| 截个图 | | 点击、拖拽、**Ctrl+V 粘贴**三种方式；前端压缩到 1280px / ≤220KB |
| 补充细节（折叠） | | 复现步骤、你希望它是什么样。默认收起 |
| 我的反馈（折叠） | | 有历史记录时才出现；提交成功后自动展开 |

## 字段映射（学生看到的 → 数据库）

学生不用懂这些，但后台仍能看到结构化信息：

| 界面 | 数据库字段 |
|---|---|
| 一句话描述 | `title` |
| 功能标签 | `preconditions` = `功能：音游节奏` |
| 情况标签 + 一句话 | `actual_result` = `问题类型：卡住不动\n音游第三关音符突然不动了` |
| 还能继续玩吗 | `priority` = P3 / P1 / P0 |
| 复现步骤 | `steps` |
| 你希望它是什么样 | `expected_result` |

**后端校验已放宽**：只要求 `title` 非空，其余全部可选（原来强制 title + steps + expectedResult + actualResult）。
后台详情弹窗本来就会过滤空字段，所以不会出现一堆空标签。

## 交互细节

- **草稿自动保存**：填到一半切页面 / 刷新，内容还在（localStorage `bug-feedback-draft`）。提交成功后清除。
- **提交后**：清空表单、显示编号 `BUG-00001`（放大加粗，学生要报给老师）、自动展开历史。
- **Ctrl + 回车** 提交。
- **来源自动识别**：`App.vue` 在切到反馈页时记下来源页面，`from` prop 传进来预选功能标签。

## 布局约束

- 主表单宽 760px 居中，**1366×768 下提交按钮在首屏内**（机房主场景）。
- 移动端 ≤640px 单列，严重程度三档改竖排。
- 折叠区默认收起，保证首屏只有「必填 + 常点」的内容。

## 踩过的坑

**全局 `textarea` 规则会漏进来。** `style.css` 有一条

```css
textarea{display:block;width:calc(100% - 64px);min-height:90px;margin:0 32px;...}
```

是给练习页写的大输入框。反馈页的 textarea 继承了 `margin:0 32px`，在 390px 宽度下直接横向溢出。
组件里必须显式覆盖 `margin:0; min-height:0; width:100%; min-width:0`。

**`min-width:auto` 也会撑破 grid。** `.q` 是 grid 容器，子项默认 `min-width:auto`，
textarea 的固有宽度会把列撑出卡片。加 `.q > *{min-width:0}`。

## 验收

```bash
# 需要先起一个临时实例（不要打生产库）
BASE=http://127.0.0.1:3300 node scripts/verify-bug-feedback.mjs
```

`scripts/verify-bug-feedback.mjs` 覆盖：布局与首屏可见性、只填一句话就能提交、标签选中、
提交后清空 + 编号、草稿恢复、补充细节展开、390px 无横向溢出、无 console/page 错误。

`node --test` 里 `test/api.test.js` 的「学生反馈：只填一句话就能提交」覆盖后端校验放宽与字段映射。

## 使用边界

- 反馈仍然只关联学生账号，未登录时显示登录引导。
- 图片仍然只支持 PNG / JPG / WebP，单张压缩后 ≤220KB。
- 「问题类型」是多选标签，最多 7 个，不做自由文本。
