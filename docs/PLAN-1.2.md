# 字练场 1.2 阶段计划

## 第一阶段：班级与分组基础

- 保留现有学生账号、成绩、训练记录和成长数据。
- 新增班级表和班级成员关系表，支持学生转班并保留历史关系。
- 后台显示待分班学生。
- 支持创建、编辑、启用/停用班级。
- 支持批量把已注册学生加入班级。
- 学生转入新班级时自动结束原班级关系，不删除历史数据。

## 后续阶段

- 班级维度的教师任务发布。
- 班级训练统计、课堂实时大屏和班级排行。
- 训练数据导出。

## 数据原则

- 不要求已有学生重新注册。
- 不迁移、不覆盖历史训练记录。
- 未分班学生仍可正常登录和练习。
- 班级关系通过独立关系表维护，支持后续转班和历史追溯。
