# 下周现场打字比赛方案 v7

> 本方案是现场使用口径。老师手动登记总积分；系统负责每局成绩与胜负。旧版 1v1 用时淘汰赛、同题团队循环赛保留在代码中，不作为本次现场比赛入口。

## 个人赛：中文与英文分开举办

1. 老师在后台选择“中文打字”或“英文打字”，设置统一时长，创建赛事并开启检录。
2. 学生登录后打开比赛页即自动报名（不需要点“加入比赛”）；老师确认人数后点击“开始比赛”，单人也能开赛。所有学生看到同一段 5 秒倒计时，倒计时结束才开放输入和计时。
3. 本场所有学生获得同一篇文章，使用服务器统一开始时间。
4. 到时系统冻结输入，按正确字数排序。由于每人比赛时长相同，正确字数越多，打字速度越快；准确率用于同字数时排序。打完整篇后立即记录该选手的完成时间，即使准确率较低，也不会卡住输入；准确率仍会显示并参与同字数排序。
5. 结果显示姓名、正确字数、准确率、字/分钟、用时。若提前打完整篇，用时为实际完成时间；否则为本场统一时长。
6. 老师根据显示结果手动记录成绩。系统提供 CSV 备份。

中文和英文是两场独立赛事，老师可以分别建赛、检录和开赛。比赛文章在同一场内固定，学生中途重连时继续使用已保存的输入进度。

## 团队赛：阵营占领

1. 老师在后台设置每局时长，点击“新建团队比赛房间”。
2. 学生从首页“打字比赛”进入“团队阵营比赛”，自行选择红方或蓝方。两方有人进入后仍保持等待。
3. 裁判核对出场人员后点击“裁判开始本局”。双方看到 5 秒倒计时，之后统一开始；开赛后不接收新选手，也不自动调换阵营。
4. 逐字按原文位置判定：正确字产生攻击；错字不攻击、计入错误并清空连击，后续位置正确仍可攻击并重新积累连击。漏字、多字会导致位置错位，需要修正未提交部分。已提交的位置不再修改或重复计分。
   即使一方提前占满领地，也持续到固定时限。
5. 到时比较占领面积：红方大于 50% 则红方胜，蓝方大于 50% 则蓝方胜，正好 50% 为平局。
6. 结果停留，等待老师手动记分。下一局由老师重新创建房间和开赛。

平时的“阵营对抗”继续保持原本的自动开局玩法；正式团队比赛使用独立房间。

## 现场操作与注意事项

- 先用测试账号演练“建赛 → 检录 → 学生加入 → 裁判开赛 → 到时结果”。
- **强制报名**：学生只要登录并打开比赛页，服务端就自动把他登记为正式选手，学生不需要点“加入比赛”。
  老师一开启检录，前端会把所有已登录学生直接拉到比赛页（`#competition`），并锁住其他页面的跳转。
- **单人也能开赛**：演练时不需要凑齐两个人，一个人就可以跑完整个流程。
- **终止比赛**：后台“比赛赛事”里每一行都有「终止比赛」按钮（检录中 / 比赛中 / 暂停中都可点）。
  终止后赛事状态变「已终止」，进行中的轮次一起收掉，学生立刻被放回其他页面，成绩不再更新，且不可恢复。
- **比赛期间其他玩法临时关闭**：只要存在检录中 / 比赛中 / 暂停中的赛事，
  红蓝占领战、打 Boss、赛车、追逐、跑酷的入场接口一律返回 423，
  避免全班同时开房间抢走比赛需要的并发。终止或结束后自动恢复。
- 每场开始前，裁判在后台确认参赛人数和红蓝阵营。
- 团队比赛房间目前保存在服务进程内；服务在比赛中重启会使本局作废，应重新开局。已结束的阵营结果会保存到数据库。
- 老师手动记录总分；系统不会自动管理跨局积分。
- 普通训练和旧版比赛入口不要用于本次现场计分。

## 验收重点

- 中文、英文个人赛各自同题、同开始时间，限时到后每人显示正确字数、速度和用时。
- 团队比赛两方有人时不会自行开赛，只有后台裁判能开始。
- 团队比赛不会自动平衡人数或在占满领地时提前结束。
- 固定时间到后按领地比例判定胜负或平局，结果不会自动开启下一局。
