# 比赛模式业务设计 v5（已确认，开始实现）

> 状态：**设计已确认**，按 M1–M6 分期实现
> 场景：年级/校级正式比赛 · 老师主持台控场 · 只出成绩表 · 赛事转播风视觉
> **两条独立赛道**：个人淘汰赛（手速，用时短者晋级）/ 团体循环赛（队伍单循环积分）

## 一、两条赛道

| | 个人赛 | 团体赛 |
| --- | --- | --- |
| 赛制 | 用时淘汰赛，每轮淘汰一半 | 单循环联赛，队队交手 |
| 单位 | 个人 | 队伍（一队一个班，数量可变） |
| 胜负 | 用时短者晋级 | 单场由老师判定，赢队记 1 分 |
| 轮次 | 每轮砍一半，直到决出 1/2/3 名 | N 队打 N−1 轮，每轮同时多场 |
| 关系 | **两条赛道独立建赛、独立开赛**，按时间安排先后办 | 同左 |

老师建赛时先选类型：**个人淘汰赛** 或 **团体循环赛**。两个赛事互不干扰。

**与现有实现的差别**：现在代码里跑的是「**90 秒内比谁打对的字多**」，时间到自动结算。本设计是「**打完整篇比谁快**」，用时短者晋级。判定口径完全不同，旧赛制由本设计**直接替换**。

## 二、个人赛（用时淘汰赛）

**个人赛算手速**：同一篇文章，谁先打完谁快，用时短者晋级。

### 一轮怎么比

```
轮次准备 → 全屏倒计时 → 计时开始 → 打完整篇 → 记录用时 → 本轮时限到 → 排名 → 淘汰
```

1. 本轮全员同一篇文章。
2. 打完最后一个字、且准确率 ≥ 门槛 → 记为「完成」，用时 = 完成时刻 − 开始时刻。
3. 本轮时限到 → 没打完的按已完成字数排名，排在完成者之后。
4. 按用时排名，保留前 N 名晋级，其余转观战。

### 淘汰人数：自动算 + 老师可改

主持台每轮开始前显示：

```
本轮 40 人参赛，按 50% 自动计算 → 晋级 20 人（淘汰 20 人）
[ 改成：保留 ___ 人 ]  [ 改成：淘汰 ___ 人 ]
```

- 手动值只作用于本轮，下一轮回到自动计算。
- 至少保留 2 人；剩 3 人及以下进决赛轮，不再淘汰。

40 人按默认 50%：`40 → 20 → 10 → 5 → 3 → 决赛`

### 计分口径

| 项 | 规则 |
| --- | --- |
| 主指标 | 用时（秒，保留 1 位小数） |
| 完成条件 | 打完整篇 **且** 准确率 ≥ 门槛 |
| 未完成 | 排在完成者之后，按已完成字数降序 |
| 并列 | 用时相同 → 准确率高者在前；仍相同 → 先完成者在前 |

## 三、团体赛（单循环联赛）

### 3.1 队伍：老师建队，学生自己进

**系统不做任何分配** —— 不均衡、不按班级字段推断、不随机。

| 谁 | 做什么 |
| --- | --- |
| 老师 | 建赛时先建好队伍：填队名（如「一班」「二班」）+ 选颜色 |
| 学生 | 报名时从队伍列表里**自己选**自己班那一队，点了就进 |
| 老师 | 只在出问题时改派（选错队、扎堆） |

每队三样东西：

| 属性 | 说明 |
| --- | --- |
| 队名 | 老师填，如「25 级电商一班」 |
| **颜色标识** | 红 / 蓝 / 绿 / 黄 / 紫 / 橙，**只用于区分，不代表任何固定含义** |
| 成员 | 学生自己加入，人数不限 |

- 颜色由系统按建队顺序给个默认值，老师可以改。
- 界面上一律显示「颜色块 + 队名」，不出现「红队 vs 蓝队」这种固定说法。
- 队数建议 4–8 支；少于 2 支不能开赛。

举例：一班和二班比，老师在主持台建「一班」「二班」两队，一班学生报名时选「一班」，二班学生选「二班」，就这样。

### 3.2 单循环怎么排：轮转法并行

**关键：不能一场一场串行打。** 8 队单循环是 28 场，串行每场 4 分钟 = 2 小时。

正确做法是轮转法编排，每轮所有队同时上场：

| 队数 | 场次总数 | 轮数 | 每轮同时进行 |
| --- | --- | --- | --- |
| 4 | 6 | 3 | 2 场 |
| **5** | **10** | **5** | **2 场 + 1 队轮空** |
| 6 | 15 | 5 | 3 场 |
| 8 | 28 | 7 | 4 场 |

**5 个班（本次实际情况）**：10 场、5 轮，每轮 2 场同时打 + 1 队轮空。
每轮 4 分钟（3 分钟比赛 + 1 分钟换场）× 5 轮 = **20 分钟打完**。

> 奇数队时每队都会轮到一次轮空，是**平衡**的，所以轮空不需要额外给分。

### 3.3 一场对战怎么打

```
抽签定对阵 → 两队同时上场 → 同一篇文章 → 全屏倒计时 → 计时开始
→ 全员打完整篇 → 按用时排出个人名次 → 老师判定哪队赢 → 赢队记 1 分
```

**系统负责把比赛跑对，记分是次要的：**

| 系统自动做 | 老师手动做 |
| --- | --- |
| 同题下发、统一计时、逐字判定 | 判定哪队赢（点一下） |
| 实时个人排名（按用时） | 记分 / 改分 |
| 两队成员用时对比（各人用时 + 队内合计） | 争议时人工裁定 |

主持台在每场结束后显示两队成绩对比，老师点「一班胜」或「二班胜」即记 1 分；也可以直接手改积分。

**系统给出的判定依据**（单场结束自动生成，供老师裁定）：

| 依据 | 说明 |
| --- | --- |
| 各成员用时 | 两队每个人逐个列出用时、准确率 |
| 队内用时合计 | 全队用时相加，少者在前 |
| 队内平均用时 | 除以参赛人数，人多人少都能比 |
| 完成人数 | 时限内打完整篇的人数 |
| 系统建议 | 按「队内平均用时」先给一个结论，附上差距（如「建议一班胜，平均快 2.3 秒」） |

老师点确认即采用建议，也可以无视建议直接选另一队。**系统只提供依据，不替老师做决定。**

### 3.4 联赛积分与排名

| 结果 | 积分 |
| --- | --- |
| 赢一场 | **1 分** |
| 输一场 | 0 分 |
| 轮空 | 不计（单循环里每队轮空次数相同，天然平衡） |

排名依次比较：积分 → 相互战绩 → 队内用时合计（少者在前）。

5 个班的完整赛程：每队打 4 场，共 10 场，5 轮打完，最高 4 分。

循环赛全部打完后：

- **积分前 2 名加打一场决赛**定冠军（已确认，默认开启）。
- 决赛同样按单场规则：同题、比用时、老师判定，赢者夺冠。
- 第 3 名及以后按循环赛积分直接排定。

> 积分也支持老师手动修改，用于现场裁定争议场次。

## 四、两种赛程（单日 / 跨天）

| | 单日快赛 | 跨天赛事 |
| --- | --- | --- |
| 个人赛 | 当天跑完 | 每天 1–2 轮，进度保存 |
| 团体赛 | 当天打完所有轮（8 队约 28 分钟） | 每天打几轮，第二天继续 |
| 时间 | 一个开赛时间 | **每轮单独设计划时间**，到点自动开赛 |
| 中断 | 进程重启本场作废 | 「今日结束」→ `paused` → 明天恢复 |

**硬前提**：跨天必须持久化。现在比赛房间在服务端内存，重启就没了 —— 这一层要新建。

## 五、赛制参数：全部由老师设置

**现在的实现把这些写死在代码里**（90 秒一局、60 秒、15 秒集合……），正式比赛必须能改。

所有参数在**建赛时设置**，赛事一旦开始**锁定不可改**（防止中途改规则影响公平）。

| 参数 | 默认 | 可选范围 | 说明 |
| --- | --- | --- | --- |
| 检录时长 | 10 分钟 | 1–60 分钟 | 建赛后等学生加入的时间 |
| 开赛倒计时 | 3 秒 | 3 / 5 / 10 秒 | 点开始后的全屏倒计时 |
| **每轮时长上限** | **3 分钟** | 30 秒 – 10 分钟 | 个人赛每轮、团体赛每场共用 |
| 轮间间隔 | 1 分钟 | 10 秒 – 10 分钟 | 一轮结束到下一轮开始 |
| 成绩展示时长 | 30 秒 | 10 秒 – 5 分钟 | 结算画面停留时间 |
| 准确率门槛 | 95% | 90 / 95 / 98 / 100 | 低于此不算完成 |
| 淘汰保留比例 | 50% | 25 / 50 / 75 | 每轮保留比例，可手动改本轮 |
| 单场胜负判定 | 老师判定 | 老师判定 / 系统建议 | 系统给依据并建议，老师确认或改判 |
| 循环后是否加决赛 | **是** | 是 / 否 | 团体赛积分前 2 名加打一场定冠军 |

跨天赛事额外为每一轮设置**计划开始时间**（精确到分钟）。

## 六、数据模型（新建）

| 表 | 关键字段 |
| --- | --- |
| `competitions` | id、名称、类型（个人/团体）、赛程（单日/跨天）、状态、**参数 JSON** |
| `competition_rounds` | id、赛事 id、轮次序号、题目 id、计划开始时间、实际起止、状态、本轮保留人数 |
| `competition_entries` | 赛事 id、用户 id、座位令牌、**队伍 id（个人赛为空，团体赛由学生自选）**、加入时间、到达轮次、最终名次、状态 |
| `competition_round_results` | 轮次 id、用户 id、正确字数、尝试字数、准确率、用时、完成时间、名次、是否晋级 |
| `competition_teams` | 赛事 id、队名、**颜色**、成员数 |
| `competition_matches` | 赛事 id、轮次序号、队 A、队 B、状态、起止时间、A 总分、B 总分、胜方 |

状态机：

```
draft → registration → running ⇄ paused → finished
```

重启后从 `competitions.status` + 当前轮次重建内存房间，选手重连自动归位。

## 十一、边界情况

| 情况 | 处理 |
| --- | --- |
| 人数为奇数（个人赛） | 按保留比例向上取整，如 5 人保留 3 人 |
| 队数为奇数（团体赛） | 每轮 1 队轮空；单循环下每队轮空次数相同，不计分 |
| 打不完 | 按已完成字数排名，排在完成者之后 |
| 中途掉线 | 保留座位与进度，重连继续；超时未回，老师可踢 |
| 跨天缺席 | 该轮记 0 分排最后，按规则淘汰 |
| 某队人数不足 | 该队照常参赛，人少不影响比赛运行；胜负由老师判定 |
| 两队人数相差悬殊 | 同上，系统不强制折算人数，老师判定时可自行参考队内用时合计 |
| 某队 0 人报名 | 该队不参与抽签，抽签时自动剔除，并提示老师 |
| 学生报名时没选队 | 进不了赛场，页面提示「请先选择你的队伍」 |
| 学生选错队 | 老师可在检录期结束前改派；开赛后不可改 |
| 某场无人完成 | 全部按字数排名；胜负由老师判定 |
| 单场争议 | 老师可直接手改该场胜负与积分 |
| 重复提交 | 以服务端第一次记下的完成时间为准 |
| 只剩 1 人/1 队 | 不开赛，提示「至少需要 2 人 / 2 队」 |
| 老师忘了推进 | 每轮结束停住等老师点「开始下一轮」，不自动跳 |
| 跨天中途服务重启 | 从数据库恢复，选手重连回到原座位与当前轮次 |
| 中途要加人 | 个人赛默认不允许；团体赛可在检录期外补录，从当前轮开始计 |
| 赛事开始后想改时长 | 不允许，必须新建一场（避免中途改规则） |
