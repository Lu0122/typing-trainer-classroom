# 字练场 · Windows 免安装运行版

适用于 Windows 10 / 11，64 位电脑。无需安装 Node.js、npm 或开发工具，首次使用也不需要联网下载依赖。

## 开始使用

1. 将 ZIP **完整解压**到可写入的文件夹，例如桌面或 D 盘。不要在压缩包预览中直接启动。
2. 双击 **启动字练场.bat**。程序会自动在默认浏览器打开**管理后台**（`http://127.0.0.1:端口/admin`），并在窗口中打印两条链接：
   - **本机后台**：只有这台电脑能打开，老师自己用；
   - **发给学生的链接**：一行一个地址（形如 `http://192.168.x.x:3000`），复制这一条发到班级群即可。
     窗口会自动跳过 WSL、Hyper-V、VMware、VPN 等虚拟网卡的地址，只保留教室网络的真实地址。
3. 老师使用这一台电脑运行服务；学生在同一局域网的浏览器里访问**发给学生的链接**，不需要每台电脑都运行一个服务。
4. **不要关闭这个黑色窗口**：关掉窗口 = 服务停止，全班学生都会断线。停止时输入 `q` 并回车，或按 Ctrl+C。停止服务会中断正在进行的比赛。

如果默认 3000 端口被占用，会尝试附近的空闲端口，请以窗口显示的实际地址为准。同一个运行文件夹重复启动时，会打开已运行的页面。

Windows 防火墙首次询问时，为课堂所在的专用网络允许访问。学生需要和老师连接同一局域网。

## 更新到新版本

1. **先关掉「启动字练场」的黑色窗口**（服务在跑时 Windows 会锁住程序文件，更新必然失败）。
2. 双击 **更新字练场.bat**。它会连到 GitHub 拉取最新代码，只下载内容变过的文件（通常 2–3MB），
   逐个校验 SHA-256 后覆盖 `public/`、`backend/server.js`、`launcher.cjs`。
3. 看到「✓ 更新完成」后，重新双击 **启动字练场.bat** 即可。学生**不需要做任何事**，刷新页面就是新版。

更新**不会动** `data/`（学生成绩）、`.env`（后台密码）、`runtime/`、`node_modules/`。

**数据库不会被覆盖**：更新只替换程序文件，`data/typing.db` 保持原样。
以后版本新增字段时，程序会先把整个库备份到 `data/backup/typing-v<旧版本>-<时间>.db` 再升级结构，
而且只做「加字段」，不删表不删列。万一升级出问题，停掉服务，
把备份文件改名成 `typing.db`（同时删掉 `typing.db-wal`、`typing.db-shm`）再启动即可。

**更新后如果有问题**：双击 **回滚字练场.bat**，退回到更新前的版本，再重新启动。
每次更新都会把被替换的文件备份到 `backup/时间戳/`，回滚成功后该目录会被清理。

**没有网络时**：更新会提示「连不上更新源」并直接退出，不会改动任何文件，服务照常可用。
如果访问 GitHub 很慢，可以在命令行里指定镜像：

```bat
set TYPING_UPDATE_URL=https://你的镜像/字练场/release
"%~dp0runtime\node.exe" "%~dp0update.cjs"
```

只想看有没有新版、不实际更新：`runtime\node.exe update.cjs --check`。

## 数据与设置

- 新运行包的 `.env` 来自示例配置，不包含开发机的密码、API 密钥或本机配置。首次使用前请修改后台密码并按课堂需要设置；如使用 AI 设置，请配置独立的随机长字符串 `AI_SETTINGS_SECRET`。已有数据库的管理员密码以数据库中的账号为准。
- 运行包不携带原项目的学生账号、成绩或比赛数据。首次运行会在 `data/` 下自动创建数据库与日志；内置题库已经包含。
- 如需迁移现有账号和成绩，先停止旧服务，再把旧项目完整的 `data/` 文件夹复制到新运行包根目录，然后启动。不要在服务运行中覆盖数据库。
- 更换运行包版本时，保留自己的 `.env` 和 `data/`。日志位于 `data/runlogs/server-events.log`。
- 可编辑 `.env` 中的 `PORT` 修改默认端口。默认数据库路径 `./data/typing.db` 随运行文件夹保存；若改为绝对路径，搬到另一台电脑前请检查该配置。

## 开发者重新打包

在开发项目根目录执行 `npm run package:win`，输出位于 `output/packages/`。该命令在独立输出目录构建当前前端、合并服务端、复制与 SQLite 匹配的 Windows x64 Node 运行时，再生成 ZIP。

包内没有完整开发依赖、历史前端构建、测试与 Git 历史。`release-manifest.json` 记录版本与文件校验值，第三方许可位于 `licenses/`。

## 课堂连接排查

- 课前请用一台学生电脑打开启动窗口中的学生链接，并试一次登录；不要把老师用的 `127.0.0.1` 后台地址发给学生。
- 学生看到“暂时无法连接教师机”时，页面会自动重连，也可以点“重试”。请检查学生与教师机的教室网络、教师机的服务窗口及 Windows 防火墙；本机能打开后台并不代表学生网络一定能访问。
- 教师机重启程序或更换网络后，IP 或端口可能变化，请以启动窗口新显示的链接为准。若地址变化，学生需要打开新链接；原页面无法自动发现新地址。
- 挑战结束后若提示成绩尚未确认，请保持页面打开等待重试，不要立刻重新开始。恢复连接后仍显示失败时请联系老师；超过服务端允许的提交时间或服务重启后的会话能否恢复，以实际返回结果为准。
- 比赛、游戏的实时状态可能因服务重启而结束；断线期间的计时和成绩以服务端规则为准。建议正式上课前用实际教室网络和预计人数试运行。
