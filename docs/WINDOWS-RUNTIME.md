# 字练场 · Windows 免安装运行版

适用于 Windows 10 / 11，64 位电脑。无需安装 Node.js、npm 或开发工具，首次使用也不需要联网下载依赖。

## 开始使用

1. 将 ZIP **完整解压**到可写入的文件夹，例如桌面或 D 盘。不要在压缩包预览中直接启动。
2. 双击 **启动字练场.bat**。程序会自动在默认浏览器打开**管理后台**（`http://127.0.0.1:端口/admin`），并在窗口中打印两条链接：
   - **本机后台**：只有这台电脑能打开，老师自己用；
   - **发给学生的链接**：一行一个地址（形如 `http://192.168.x.x:3000`），复制这一条发到班级群即可。
     窗口会自动跳过 WSL、Hyper-V、VMware、VPN 等虚拟网卡的地址，只保留教室网络的真实地址。
3. 老师使用这一台电脑运行服务；学生在同一局域网的浏览器里访问**发给学生的链接**，不需要每台电脑都运行一个服务。
4. **不要关闭这个黑色窗口**：关掉窗口 = 服务停止，全班学生都会断线。停止时输入 `q` 并回车，或按 Ctrl+C。停止服务会中断正在进行的比赛。

如果默认 3000 端口被占用，会尝试附近的空闲端口，请以窗口显示的实际地址为准。同一个运行文件夹重复启动时，会打开已运行的页面。

Windows 防火墙首次询问时，为课堂所在的专用网络允许访问。学生需要和老师连接同一局域网。

## 数据与设置

- 运行包包含打包时的 `.env`，后台密码、账号审核等设置沿用此文件；它可能包含敏感配置，只交给需要这些配置的管理人员。
- 运行包不携带原项目的学生账号、成绩或比赛数据。首次运行会在 `data/` 下自动创建数据库与日志；内置题库已经包含。
- 如需迁移现有账号和成绩，先停止旧服务，再把旧项目完整的 `data/` 文件夹复制到新运行包根目录，然后启动。不要在服务运行中覆盖数据库。
- 更换运行包版本时，保留自己的 `.env` 和 `data/`。日志位于 `data/runlogs/server-events.log`。
- 可编辑 `.env` 中的 `PORT` 修改默认端口。默认数据库路径 `./data/typing.db` 随运行文件夹保存；若改为绝对路径，搬到另一台电脑前请检查该配置。

## 开发者重新打包

在开发项目根目录执行 `npm run package:win`，输出位于 `output/packages/`。该命令在独立输出目录构建当前前端、合并服务端、复制与 SQLite 匹配的 Windows x64 Node 运行时，再生成 ZIP。

包内没有完整开发依赖、历史前端构建、测试与 Git 历史。`release-manifest.json` 记录版本与文件校验值，第三方许可位于 `licenses/`。
