# 字练场

当前 1.1 教学闭环计划和实施状态见 [PLAN-1.1.md](PLAN-1.1.md)；1.2 班级与分组阶段计划见 [PLAN-1.2.md](PLAN-1.2.md)。四种联机玩法的机制升级与验证见 [GAMEPLAY-QA.md](GAMEPLAY-QA.md)。

面向中文与英文输入的打字练习应用，包含 Vue 3 前台、自由练习、字幕键位新手入门、英文/拼音文章挑战、学生账号、60 秒竞速、个人最好成绩排行榜和管理后台。后端使用 Node.js + Express，数据保存在 SQLite。

自由练习带有完整的 128 键扩展虚拟键盘。物理按键按下、长按和抬起会实时反映到对应键位，并显示标准 `KeyboardEvent.code`；挑战模式使用文章输入框和服务端计时，手机窄屏可横向查看，密码输入期间会自动隐藏键盘反馈。

“键盘熟悉”模式不要求登录，先用手位摆放页学习 F/J 基准键和左右手指分工，再进入连续练习。练习支持基准键、上排、下排、数字、标点和全键混合六关；物理键盘和虚拟键盘都可以按目标键，系统会统计连续正确、准确率与本轮进度。

## 启动

```bash
npm install
npm run build
npm start
```

打开 `http://localhost:3000`，管理后台位于 `http://localhost:3000/admin`。

`npm run dev` 会先构建前端页面，再启动后端，默认监听 `0.0.0.0:3000`，同一局域网设备可使用启动日志中显示的 `http://本机IP:3000` 访问。若 Windows 防火墙首次询问是否允许 Node.js 访问专用网络，需要选择允许。开发模式采用稳定启动方式；修改前端或后端代码后停止并重新运行一次 `npm run dev` 即可加载更新。首次运行前请先执行 `npm install`。`public/index.html` 和前端构建文件不纳入 Git，直接运行 `node src/server.js` 前需要先执行 `npm run build`，否则首页会显示 `Cannot GET /`。

前台已迁移为 Vue 3 + Vite，首页提供“新手入门”“英文打字”“拼音打字”“挑战模式”“游戏模式”五个入口。新手入门包含基准键、上排、下排、数字、标点和全键混合 6 关，每关 120 至 180 个目标键。英文打字包含 10 套单词、10 套语句和 8 篇文章；拼音打字包含 6 套音节、8 套词组和 8 篇文章。长单词和语句按输入进度分段显示，完成当前素材后会自动进入下一套，也可通过课程下拉框直接选择。挑战模式分英文挑战和拼音挑战，均为一分钟文章输入，结束后由服务端计算并提交对应排行榜。游戏模式提供单房间红蓝打字占领战，使用 36×18 真实格子记录前线，题目包含中文励志文章、英文语句和代码练习，Three.js 播放单位冲锋、点状弹道、命中爆炸和逐格翻色。Express 继续负责 API、SQLite、登录和后台。

默认管理密码为 `admin123`。正式使用前建议复制配置文件并修改密码：

```powershell
Copy-Item .env.example .env
# 编辑 .env，把 ADMIN_PASSWORD 改成你的新密码
npm start
```

项目启动时会自动读取根目录的 `.env`，也支持由进程管理工具直接注入同名环境变量。

如果通过 HTTPS 部署，请把 `COOKIE_SECURE` 改为 `true`。`REQUIRE_ACCOUNT_APPROVAL` 默认开启：学生注册后，老师需要在“后台 → 学生账号”核对姓名并启用账号，才能登录参加竞速。这样可以减少小号占榜。如果是可信的小范围环境，可显式设置为 `false` 关闭审核。

## 学生账号与排行榜规则

1. 学生注册只需填写姓名和密码；姓名必须唯一且不能包含违规或敏感词，系统自动生成内部账号标识。密码为 6 至 12 位，只允许纯数字或字母数字组合。
2. 学生登录可使用姓名或系统内部账号，展示姓名用于排行榜。
3. 老师在后台启用账号；忘记密码时可由老师安全重置。
4. 登录状态以 HttpOnly Cookie 保存，会话摘要持久化在 SQLite，浏览器或服务重启后仍可继续使用。
5. 竞速挑战和成绩都绑定账号，不能替其他账号提交，也不能通过请求伪造昵称。
6. 每个学生在总榜和今日榜中只占一行，取该时间范围内的个人最好成绩；同字数时正确率高者在前。

密码使用 Node.js `scrypt` 加盐哈希；会话令牌只以 SHA-256 摘要保存。接口还包含登录失败限流、同源校验、严格 Cookie、CSP 安全策略、服务端计时和幂等交卷。

## 数据

- SQLite 数据库默认保存在 `data/typing.db`。
- 首次启动自动创建表并写入普通练习素材及英文/拼音挑战文章。
- 账号、登录会话、竞速成绩均持久化在 SQLite。
- 竞速成绩由服务端按照原文重新计算，英文挑战和拼音挑战分别抽取文章、分别计算排名，且必须等待服务器记录的 60 秒结束后才能提交。

## 游戏选择

大厅现有六个入口：遗迹逃亡（`/#runner`）、打字赛车（`/#race`）、生死时速（`/#chase`）、字母音游（`/#rhythm`）、极速淘汰赛（`/#boss`）、红蓝占领战（`/#battle`）。各模式独立运行；遗迹逃亡是单人无限冒险，赛车支持四人房和邀请码，生死时速支持双人房与人机。

- **遗迹逃亡**：登录后选择英文单词或中文词句，3 秒倒计时结束后输入框自动获得焦点。在障碍到达前打完目标文字，跑者会自动跳过断桥、滑过石门或向左右避障；可修改错字，无需回车。每 10 个障碍升一关，路线持续生成，速度和题目难度逐步提高，三次未完成后结算。关节角色、石桥、藤蔓与棕榈使用 Three.js 原创制作；丛林远景与苔藓石材由内置 ImageGen 生成并随项目保存，素材说明见 [runner 资源说明](public/assets/runner/README.md)。
- 道路与装饰逐个循环回收，动画时钟平滑吸收服务器校时；经过的障碍会继续移到角色身后。跳跃落地有扬尘，通过障碍有光环和粒子，碰撞有火花、后仰、短暂画面反馈及对应音效。右上角可切换“自动 / 流畅 / 精细”画质；默认自动画质会按帧率和像素预算调整渲染精度，重复场景使用实例化合并绘制。输入框与按钮适配窄屏，减少动态效果的系统偏好会关闭震动、镜头抖动及 UI 动画。
- 逃亡排行榜分中英文组，支持总榜和今日榜（北京时间），每人保留最远纪录；同距离按得分、准确率及完成时间排序。距离、关卡和成绩由服务端计算，结算写入 SQLite 与成长记录。打开排行榜、离开游戏或切换到后台时自动暂停，继续时重新倒计时；页面刷新及服务重启后可恢复暂停进度。音效默认关闭，可在右上角开启。

- **打字赛车**：1—4 人，选手准备后由房主启动 5 秒发车倒计时。打字速度决定车速：正确输入提速，错字刹车，停手自然减速。先跑完 800 米（160 格）获胜；最多 120 秒，超时按距离排名。车速有 6 档，每字得分随档位放大 1 / 1.2 / 1.5 / 2 / 2.5 / 3 倍。打满一段自动换段，全程无需回车。
- **生死时速**：双人联机或人机，3 秒倒计时后开始，最长 2 分钟。警察追上小偷获胜，小偷坚持到时限结束获胜。正确字符推进距离，段落自动衔接；人机对手随玩家的正确输入前进。
- **字母音游**：1—60 人，112 BPM，90 秒一局。26 个字母按键位分成四条下落轨道，在判定线附近按对应字母。Perfect / Great / Good 分别为 300 / 200 / 100 基础分，与连击倍率相乘。简单、普通、困难的下落时长分别为 6.8 / 2.6 / 1.9 秒，简单谱面密度为普通的四分之一；各难度使用对应判定窗口。无需回车换段，漏键会计入结算和成长记录。
- 赛车与音游成绩保存到 `arena_results` 和成长记录，退出后保留训练数据，断线超过 20 秒移出。赛车可以重新匹配新房间；音游结算 15 秒后开放新一局。

首页“游戏模式”进入 `/#games` 大厅，可选择“极速淘汰赛”（`/#boss`）。淘汰赛为独立公共房间，支持 1—60 名已登录学生，每局最长 3 分钟；首次加入后 15 秒自动开局，队长也可提前开始。每个正确字累积积分，10/30 连击后每字积分提升；错字会中断自己的连击。

比赛每 20 秒结算一轮，按积分、正确率和连击排序，末位约 25% 选手被淘汰并进入观战，最后幸存者获胜。完整输入后按回车换段。训练聚合记录写入成长中心，结算保存至 `boss_results`。房间实时状态保存在进程内存，服务重启会结束未完成的实时对局。
